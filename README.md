# Check-K2LowLatency

A lightweight PowerShell utility that checks whether the Windows **K2 Low Latency Profile** is present and active on your system.

## Usage

Run:

powershell
.\Check-K2LowLatency.ps1


## Requirements

- Windows 11 build 22621.2792+
- PowerShell 5.1 or 7+
